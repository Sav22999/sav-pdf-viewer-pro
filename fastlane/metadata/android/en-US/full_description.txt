Sav PDF Viewer Pro is a simple, lightweight and privacy-focused PDF reader for Android, built to open your PDF files quickly without compromising your privacy.

Key features:

📚 View all your PDF files in a simple way
🔒 Safe and private — the app doesn't require any permissions*
📌 Automatically resumes the last position for each file
🔖 Create and manage bookmarks
🔐 Open PDF files protected by a password
🌙 Night mode to protect your eyes
🔗 Open links within documents
🔍 Search text
🔤 Select and copy text
↔️ Share files easily
👐 Open-source — the code is available on GitHub

*You can verify this yourself under "App details > Permissions" on this Play Store listing.

––
The app is not a pdf editor, it's a viewer
